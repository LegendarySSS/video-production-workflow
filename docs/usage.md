# 使用说明

## 安装和启动

安装方式见 [仓库首页](../README.md)。技能文件位于 skills/video-production-workflow，需保留完整目录。

安装后发送：

> 使用 $video-production-workflow 帮我建立一个视频项目。我还没确定方向，也没有生成工具。先完成创作简报和小样方案，不调用付费服务。

## 动态短剧要求

先确认交付形态与实际可用视频工具。短剧默认需要角色真实完成约定表演；静态图片配台词只是预演。人物不动、只有图片缩放或字幕变化，也不能据此宣称动态制作完成。

让 Agent 先做一个有代表性的动态镜头，检查人物动作和本片需要的对白形式，再制作其他镜头。只有出图与配音能力时，保存 awaiting_external，交付视频工具输入包；用户明确接受静态形式后才改变目标。

已装旧版的用户需要更新技能并新开会话；继续旧项目时先复核交付约定和已选素材，旧的预演通过记录不能自动当作动态成片验收。

## 制作与恢复

每部作品使用独立目录，以技能内的 assets/project-template.json 为起点保存 project.json。角色图、场景、分镜、候选素材和交付文件放在项目内；技能目录只保存通用规则。

- 继续制作：指定项目目录，先读取 project.json，再执行下一项任务。
- 修改镜头：指定镜头编号和修改范围，保留已通过版本，检查相邻镜头。
- 外部工具：整理输入包和操作清单，把尚未执行的部分记为 awaiting_external；素材回传后继续验收。
- 项目交接：提供项目文件、选中素材、缺失文件、访问依赖及下一步。

## 角色一致性

先批准角色标准图，再补剧情需要的角度与动作测试。角色的固定特征与场次服装、持物等状态分别记录。每个镜头既对照原始身份基准，也检查前后镜头衔接；不要只靠连续截图接力。

## 个性化

个人或品牌偏好放在独立文件，调用时指定位置。本项目决定默认只影响本项目，只有明确要求长期沿用时才更新个人规范。不把客户素材、私人称呼或账户凭证写入通用技能。

## 能力边界

技能不附带视频、配音或剪辑工具。无相应能力时输出文案和执行清单，不标记素材或影片已完成。抽帧用于筛查，不能替代完整播放验收；未执行的检查标为 pending。

建议先用一个角色、少量场景的小样跑通一次流程，再根据实际返工记录调整规范。
