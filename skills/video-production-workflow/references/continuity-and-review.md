# 角色、场景与连续性验收

## 角色资产

1. 从用户已有参考或选定候选中确定身份基准，记录 approved_reference_ids；不能把任意生成图都当批准素材。
2. 按剧情需要补正面、四分之三侧面、侧面、全身与表情。逐张对照基准，多角度图本身也需要验收；不要把多个人混成参考包。
3. 固定身份特征与可变状态分开：脸部结构、身形等属于 identity；服装、发型、伤痕、湿润程度等按 scene 记录。
4. 建立最小试镜集，覆盖影片确实需要的近景、侧脸、转头、对白、遮挡或全身动作，不为不需要的能力额外生成素材。
5. 角色编号是项目引用标识，不能代替工具实际支持的参考图片或角色资产输入。只用正脸不能视为已验证其他机位。

## 场次状态

- 记录场景布局、人物站位、主要道具、光源与时间，必要时附俯视图。
- 人物自身左右、画面左右和世界空间方向分开表达。
- 记录道具归属与持握手、服装状态、视线目标、动作起止。剧情造成的变化写入具体镜头的 state_in 与 state_out。
- 允许有意越轴、跳切或状态变化，但记录创作意图，避免把风格选择误判成错误。

## 每个候选的检查

| 维度 | 看什么 | 失败后优先处理 |
|---|---|---|
| 身份 | 脸部结构、发际线、身形和已定义特征 | 回到标准资产，重新制作关键帧或调整参考输入 |
| 动态交付 | 角色是否实际完成约定动作或表演，而非仅有图片缩放、平移、字幕或转场 | 返回动态镜头制作；静态预演标明用途，不能作为动态短剧交付 |
| 时间稳定 | 转头、说话、遮挡、运动中是否变形或换人 | 缩短、拆动作、降低该镜头负担，必要时换制作路径 |
| 身体与交互 | 肢体、接触、抓握、物体数量和运动 | 改动作或构图，单独测试交互段 |
| 场记 | 服装、持物、伤痕、湿润、门窗与桌面物品 | 校正场次状态与镜头输入 |
| 空间 | 走向、机位、视线与前后镜头是否成立 | 对照场景布局重排或重做相关镜头 |
| 声音 | 声线、对白内容、口型、背景声与同步 | 按实际工具修音、重配或重做；不要仅凭静帧判通过 |
| 剪辑 | 动作接点、节奏、曝光色彩和声音衔接 | 放进时间轴检查相邻镜头，局部修复 |

先对照关键帧，再检查开头、中间、结尾和动作转折处。抽帧只用于筛查；有播放能力时完整播放候选与最终时间轴，关键动作逐帧复核。没有相应能力的维度记 pending，不能自动通过。

review 每个维度采用 pass、fail、pending 或 not_applicable；记录具体位置、现象和处理建议，不编造相似度评分。用户明确接受的缺陷记录 accepted_exception 与适用范围。

## 版本和重做

- 保留原始候选与输入，review 关联具体 generation_id，不只关联镜头。
- 镜头的 selected_generation_id 必须指向真实候选；approved 需要验收依据或明确的用户接受记录。
- 上游资产改变时只标出受影响项待复查，不删除旧素材或无条件全量重做。
- 重试次数、费用与可用镜头比例按实际记录计算。工具没有回报价格时 cost 留空，不用估计冒充实付。

短剧完整播放时检查对白期间的表演、反应与动作连续性。不是每个镜头都必须运动；按剧情设计的静止表演、空镜和停格可保留。检查的是是否完成约定表演，不用全画面像素变化、帧率、文件时长或 MP4 容器代替内容判断。
